## 这篇论文说什么

**报「拦住了 N/M」不构成任何证据**

样本可以被作者挑选、期望可以被作者设定、判定可以被作者实现
前两条在一个作者、一个语料的前提下无法根除，第三条必须根除

可接受的证据只有一种
**构造一个缺陷样本、调用真实的护栏、然后把护栏改坏，确认样本随之从「拦住」变成「漏检」**

我们实现并运行了这套变异测试，当前结果是 **假测试 0/4**

## 四次转折

| 期 | 触发 | 改了什么 |
|---|---|---|
| 史前 | 需要算得对 | 能力层 23 命令、验证三件套、23 道门 |
| R121–R122 | 论文 12 节而名单只有 7 板 | 板数改为解析 `\section`；比例关系钉进自检 |
| R123 | 用户要求「手工检查变成规则」 | 题面落地门、显著性门、文献与图的下限 |
| R124 | 外部评审批「用可核对方程替换了证明」 | `proof` 门、`iterlog` 门、图的内容检查 |
| **R125** | **自问「35 项里几道被证明过有效」** | **四层结构、域无关性、L3/L4 分离** |

**前三次由用户指令或外部评审触发，第四次是系统自己数出来的**
它数出 35 道门里只有 4 道同时具备构造缺陷与变异敏感，覆盖率 **11.4%**
这个把自己判负的结果，直接导致本文从「数门」改为「分层」

## 四层

| 层 | 对象 | 判据 | 状态 |
|---|---|---|---|
| L1 | 一个数 | 在冻结表里吗 | 已实现 |
| L2 | 一条推理 | 有非空证明吗 | 已实现 |
| L3 | 一次迭代 | 有「不信判据」吗 | 已实现 |
| **L4** | **一段轨道** | **连续同错、编辑距离、上下文占比** | **未实现** |

前三层是内容层，第四层是元层，不是「更上一层的内容」，是另一个坐标轴

## 已知缺陷（不藏）

- **零 baseline 对比** —— 唯一会被问死的
- **A/B 对照只有 n=1**
- **35 道门里 31 道没有检出能力证据**
- **L4 一行代码没有**
- **未知缺陷的检出率不可知**
